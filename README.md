# Tłumaczenia filmu o Messim — instrukcja dla koleżanki (iPad)

1. Otwórz **Claude Code** (nie zwykły czat — tylko w Claude Code tłumaczą agenci: osobny tłumacz i osobny korektor dla każdego języka, 3 języki naraz).
2. Dodaj jako załącznik plik **PACZKA.txt** (przycisk „+” → Pliki).
3. Napisz: **„Przetłumacz wszystkie języki po kolei według instrukcji z załącznika.”** Kolejność: es, ru, id, pt-PT, fr, vi, uz, ar, tr, th, pl, hu, de, cs, ro, sr, it, el, hi, zh.
4. Jeśli Claude się zatrzyma w połowie, napisz „dalej”.
5. Po każdym języku pobierz jego plik (np. `es.tsv`) i wyślij Kamilowi.

Żadnych kluczy ani haseł nie trzeba.
