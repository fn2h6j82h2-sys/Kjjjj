# Tłumaczenia filmu o Messim — instrukcja dla koleżanki (iPad), wersja 3 (27.11)

Nowość w wersji 3: plik ZASADY.md z zasadami naturalnego języka (kalki, powtórzenia, rejestr). Tłumacze piszą naturalnie i nie pilnują długości (Kamil przyspiesza głos w montażu), nie ma już kontroli wstecznej — szybciej i dużo mniej limitu.

1. Otwórz **Claude Code** (3 agentów pisze język równolegle, potem jeden korektor). Można wyjść z aplikacji; po przerwie z powodu limitu napisz „dalej”.
2. Dodaj jako załącznik NOWY plik **PACZKA.txt** (przycisk „+” → Pliki). Starej paczki już nie używaj.
3. Napisz: **„Przetłumacz po kolei według instrukcji z załącznika: tr, th, hu, de, cs, ro, sr, it, el, hi, zh.”** (es, ru, id, pt-BR, fr, vi, pl, uz i ar są już zrobione).
4. Jeśli Claude się zatrzyma w połowie, napisz „dalej”.
5. Po każdym języku pobierz jego plik (np. `uz.tsv`) i wyślij Kamilowi.

Żadnych kluczy ani haseł nie trzeba.
